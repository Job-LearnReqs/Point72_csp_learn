# 07 Base Nodes

## Read

- <https://github.com/Point72/csp/wiki/Base-Nodes-API>

## Concepts

- core built-in stream operations
- constants
- printing
- sampling or holding style operations where available
- choosing built-ins before custom code

## Practice Setup

Create `practice.py` that demonstrates at least five base nodes from the API
reference.

For each built-in, add a short comment explaining what it consumes, what it
emits, and when you would use it in a real graph.

## Checkpoint

You can replace a simple custom node with a built-in when the built-in is more
direct.
