## Concepts

- CSP means Composable Stream Processing.
- A CSP application is a graph of event-driven computations.
- The same graph logic can run against historical or realtime data.
- Inputs and outputs connect through adapters.
- Built-in nodes handle common stream operations; custom nodes express domain
  logic.
